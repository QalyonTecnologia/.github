# Qalyon Tecnologia

**Ideias que se transformam em tecnologia.**

Somos uma software house de Planaltina de Goiás. Desenvolvemos sites institucionais, portfólios, landing pages e sistemas sob medida para profissionais autônomos e pequenos negócios. Também criamos produtos SaaS próprios.

## Projetos em destaque

- [Site institucional da Qalyon](https://github.com/QalyonTecnologia/Qalyon) — código do site e do mostruário de serviços.
- [Almeida Torres Advocacia](https://qalyontecnologia.github.io/almeida-torres-advocacia/) — demonstração de site institucional para um escritório de advocacia.
- [Lívia Azevedo](https://qalyontecnologia.github.io/livia-azevedo-advocacia/) — demonstração de portfólio profissional.

## Produto próprio

**Atlas by Qalyon** está em desenvolvimento para organizar a rotina de prestadores de serviços, do orçamento ao registro do pagamento.
